2 · Paste into the Pine Editor


    
  
  1. On TradingView, open Pine Editor (bottom panel).
    2. 
  
  2. Open → New indicator.
    3. 
  
  3. Click inside the editor, Ctrl+A, then
      Ctrl+V. Paste — never type. Monaco's
      auto-indent silently corrupts hand-typed Pine.
    4. 
  
  4. Save (Ctrl+S), keep the script's own
      name, then Add to chart.
    5. 
  
  5. Set the chart to the 15m timeframe.
    6. 




3 · Create the alert


    
  
  1. Press Alt+A.
    2. 
  
  2. Condition → the scanner script's name.
    3. 
  
  3. The dropdown just below it → Any alert() function call.
      This is the setting that makes one alert cover all 40 symbols — get it
      wrong and you get nothing.
    4. 
  
  4. Notifications tab → tick Notify on app
      (this is the phone push), plus Show popup and
      Play sound.
    5. 
  
  5. Leave the message box alone. The script writes it.
    6. 
  
  6. Expiration → as far out as the plan allows, then
      Create.
    7. 





Only 2 indicators fit on a chart at once (free plan). That is
fine: an alert keeps running after you remove the indicator. So — add b1,
create its alert, remove b1 from the chart, add b2, and so on. Check the
Alerts panel afterwards; all five should read as active.





These alerts never fire on history. TradingView ignores
alert() on historical bars, and the script also gates on
barstate.isconfirmed with alert.freq_once_per_bar_close.
Nothing triggers until a real 15m candle closes while the alert is live.
