🧩 इंडिकेटरचे भाग

  • MTF व्हॉल्यूम टेबल: प्रत्येक टाइमफ्रेमवर खरेदी vs विक्री. हिरवी रो = तेजी, लाल रो = मंदी.
  • Smart Trail (जांभळी रेषा): ट्रेंड + ट्रेलिंग स्टॉपलॉस.
  • बबल्स: मोठ्या (इन्स्टिट्यूशनल) व्हॉल्यूमचे ठिकाण — हिरवे/लाल वर्तुळ.
  • जांभळे ठिपके: स्विंग हाय/लो = सपोर्ट/रेझिस्टन्स.
  • Flow पॅनल + ADX: मोमेंटम व ट्रेंडची ताकद.

🟢 LONG (खरेदी) कधी?

  • Smart Trail भावाच्या खाली पलटते → LONG सिग्नल.
  • R-Factor हिरवा (० पेक्षा जास्त).
  • टेबलमधील जास्तीत जास्त रो हिरव्या.
  • Flow हिस्टोग्राम हिरवा + शून्याच्या वर.
  • ADX > 25 = मजबूत ट्रेंड (कन्फर्मेशन).

🔴 SHORT (विक्री) कधी?

  • Smart Trail भावाच्या वर पलटते → SHORT सिग्नल.
  • R-Factor लाल (० पेक्षा कमी).
  • टेबलमधील जास्तीत जास्त रो लाल.
  • Flow हिस्टोग्राम लाल + शून्याच्या खाली.
  • ADX > 25 = मजबूत मंदीचा ट्रेंड.

⭐ R-Factor नियम

  • +33 पेक्षा जास्त = STRONG BUY → मोठी पोझिशन.
  • 0 ते +33 = BUY → छोटी पोझिशन.
  • 0 ते −33 = SELL.
  • −33 पेक्षा कमी = STRONG SELL.
  • लक्षात ठेवा: R-Factor फक्त कन्फर्मेशन आहे — एकटा सिग्नल नाही.

🎯 स्टॉपलॉस व टार्गेट

  • स्टॉपलॉस = जांभळी Smart Trail रेषा (ट्रेल करत राहा).
  • टार्गेट = पुढील जांभळा ठिपका / बबल.
  • डायव्हर्जन्स: भाव नवीन हाय पण R-Factor खाली → रिव्हर्सलचा धोका.
  • नफा झाल्यावर स्टॉपलॉस ब्रेकइव्हनला सरकवा.

⚠️ महत्त्वाचे नियम

  • ट्रेंडच्या विरुद्ध ट्रेड करू नका.
  • एकाच सिग्नलवर अवलंबून राहू नका — संगम (confluence) बघा.
  • नेहमी रिस्क मॅनेजमेंट (1–2% प्रति ट्रेड).
  • साइडवेज मार्केटमध्ये (ADX < 20) ट्रेड टाळा.
  • आधी पेपर-ट्रेड करून मगच खऱ्या पैशाने वापरा.
